# 매일 커넥트 원고

기존 블로그 앱의 **여행 커넥트 → 매일 자동 원고**에서 설정합니다.

1. 네이버에 로그인합니다. 예약 시에도 같은 앱의 로그인 세션을 사용합니다.
2. 브랜드커넥트에서 발급한 여행·쇼핑 제휴 링크를 한 줄에 하나씩 대기열에 넣습니다.
3. 텔레그램 봇 토큰을 저장하고 봇에게 메시지를 보낸 뒤 채팅을 연결합니다.
4. 매일 실행을 켜고 `07:00`으로 예약합니다. Windows 작업 이름은 `BlogAutoConnect`입니다.
5. `지금 한 번 실행`으로 저장과 알림을 확인할 수 있습니다.

하루 목표는 여행 2편 + 쇼핑 2편입니다. 대기열에서 상품 정보를 수집하고 키워드 3개를 제안한 뒤, 키워드를 자동 선택해 원고를 생성합니다. 링크에서 추출한 사진과 제휴 링크를 포함해 네이버에 임시저장하고 텔레그램으로 결과를 보냅니다. 저장 확인이 끝난 항목만 완료로 기록합니다. 실패한 항목은 대기열에 남습니다.

상품 발굴은 네이버 공개 여행·쇼핑 목록에서 후보를 추천합니다. **제휴 링크 발급까지 자동화하지 않습니다.** 추천받은 상품의 링크는 직접 발급해 대기열에 넣어야 합니다. 링크가 부족하면 목표 4편보다 적게 처리합니다.

| 담당 | 작업 |
| --- | --- |
| 코드 | 예약, 수집, 사진 다운로드, 서식, 저장, 대기열, 알림 |
| Haiku | 상품 사실 정리, 키워드 후보, 공개 상품 후보 평가 |
| Opus | 후보 키워드 선택, 제목·후킹·구성 결정 |
| Sonnet | 결정된 구성에 따라 본문 작성 |

일반 작업과 본문 작성은 사고 모드를 끄고, 중요한 기획에만 사용합니다. 모델 호출에 불필요한 도구 목록을 전달하지 않습니다.

예약은 PC가 켜져 있고 Windows에 로그인되어 있어야 실행됩니다. 네이버 로그인 만료 시 생성 전에 중단하고 텔레그램으로 로그인 필요를 알립니다. Windows 작업 스케줄러의 전원 조건도 적용됩니다.

봇 토큰과 채팅 ID는 `%APPDATA%/blog-auto/notify.json`에 저장되며 Git에 포함하지 않습니다. 대기열은 `connect-queue.json`, 실행 기록은 `daily-connect.log`에 저장합니다.
